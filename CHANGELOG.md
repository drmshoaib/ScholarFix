# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-05-25

- Added professional README, project metadata, license, citation file, and environment template.
- Standardised the canonical Streamlit entry point as `app.py`.
- Added central configuration for paths, model selection, dev mode, and Firebase credentials.
- Moved legacy prototype files into `archive/`.
- Improved helper modules with type hints, docstrings, safer HTML diff rendering, and cleaner reports.
- Added pytest coverage for text metrics, feedback checks, reporting helpers, configuration, and parser/PDF smoke paths.
- Updated `.gitignore` to keep secrets, local virtual environments, uploads, and generated reports out of version control.
